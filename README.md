Pengguna memilih makanan, memilih minuman, memasukkan jumlah pembelian, memilih kategori pelanggan, dan memilih metode pembayaran.Setelah semua data dimasukkan
program menghitung subtotal, diskon, biaya administrasi, dan total pembayaran, Program juga menerapkan konsep if, switch, operator, dan nested if untuk menentukan hasil berdasarkan kondisi tertentu.
Pengguna Sistem Kasir, untuk melakukan transaksi pembelian.,Pelanggan, sebagai pihak yang melakukan pembelian makanan dan minuman.
